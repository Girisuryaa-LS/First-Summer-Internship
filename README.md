# First-Summer-Internship
5 week Internship at Microbolt Systems , Coimbatore , Tamil Nadu , June 2025 - July 2025

# Week 1 — Product Understanding & Analysis
Studied how different types of electrical devices can be controlled <br>
&nbsp;&nbsp;&nbsp;&nbsp;Devices that work directly (lights, fans, chargers, appliances)<br>
&nbsp;&nbsp;&nbsp;&nbsp;Devices that operate through sensors or timers (motion-based systems, temperature-based systems, scheduled devices)<br>
Dismantled the existing relay controller to understand:<br>
&nbsp;&nbsp;&nbsp;&nbsp;Main controller unit<br>
&nbsp;&nbsp;&nbsp;&nbsp;Relay control section<br>
&nbsp;&nbsp;&nbsp;&nbsp;Communication ports<br>
&nbsp;&nbsp;&nbsp;&nbsp;Power supply unit<br>
&nbsp;&nbsp;&nbsp;&nbsp;Memory and networking sections<br>
Learned all input/output ports:<br>
&nbsp;&nbsp;&nbsp;&nbsp;Power, control, service, console<br>
&nbsp;&nbsp;&nbsp;&nbsp;Relay outputs, PWM outputs, analog outputs, serial outputs<br>
Studied basics of:<br>
&nbsp;&nbsp;&nbsp;&nbsp;Real-time clock operation (timekeeping, alarms, backup battery)<br>
&nbsp;&nbsp;&nbsp;&nbsp;Motor direction control using relays<br>

# Week 2 — Design Planning & Component Selection
Created the first version of the complete schematic<br>
Compared different controller options and selected a suitable one<br>
Selected a low-power real-time clock for accurate timekeeping<br>
Learned the I²C communication protocol (two-wire communication system)<br>
Selected USB-to-UART interface for communication/programming<br>
Created multiple pictorial block diagrams of the relay controller<br>
Finalized all required components based on design requirements<br>
Prepared the cost estimation for the full system<br>

# Week 3 — Complete Schematic Design
Designed individual circuits such as:<br>
&nbsp;&nbsp;&nbsp;&nbsp;USB communication section<br>
&nbsp;&nbsp;&nbsp;&nbsp;Real-time clock section<br>
&nbsp;&nbsp;&nbsp;&nbsp;Main controller connection section<br>
&nbsp;&nbsp;&nbsp;&nbsp;Relay, PWM, analog, and communication sections<br>
Combined all circuits into a complete schematic<br>
Performed multiple review cycles and made corrections<br>
Finalized the schematic and prepared it for PCB layout<br>

# Week 4 & Week 5 — PCB Layout
Started PCB layout by arranging components efficiently<br>
Improved layout through multiple review rounds:<br>
&nbsp;&nbsp;&nbsp;&nbsp;Reduced board size<br>
&nbsp;&nbsp;&nbsp;&nbsp;Improved routing and power flow<br>
&nbsp;&nbsp;&nbsp;&nbsp;Optimized ground plane and signal paths<br>
&nbsp;&nbsp;&nbsp;&nbsp;Adjusted vias and improved structural stability<br>
&nbsp;&nbsp;&nbsp;&nbsp;Improved differential signal routing<br>
Completed routing of all signal lines<br>
Finalized the PCB design with:<br>
&nbsp;&nbsp;&nbsp;&nbsp;2-layer board<br>
&nbsp;&nbsp;&nbsp;&nbsp;Inputs: Ethernet, serial input, trigger inputs, IR input<br>
&nbsp;&nbsp;&nbsp;&nbsp;Outputs: Relay outputs, PWM outputs, analog outputs, IR outputs<br>
&nbsp;&nbsp;&nbsp;&nbsp;Proper track width, spacing, and power distribution maintained
